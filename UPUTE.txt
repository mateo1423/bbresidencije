BB RESIDENCIJA — SOURCE CODE

Potrebno:
- Node.js 22.13 ili noviji

Pokretanje stranice:
1. Otvorite terminal u ovoj mapi.
2. Pokrenite: npm install
3. Pokrenite: npm run dev
4. Otvorite adresu prikazanu u terminalu.

Najvažnije datoteke za uređivanje:
- app/page.tsx — tekstovi, sadržaj, kontakt i raspored sekcija
- app/globals.css — boje, fontovi, veličine i izgled
- public/ — sve slike i grafičke datoteke

Izrada produkcijske verzije:
- npm run build
